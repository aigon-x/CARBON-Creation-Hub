# CATEGORY B DIRECTIVE — MATRIX-WIDE SYNC REQUIRED

**Authority:** Owner instruction  
**Scope:** Every AMilliMATRiX worker, office, agent, scheduled task and receiving runtime that has not yet consumed this directive.  
**Directive:** **SYNC.**

Every worker that has not seen this directive must sync with current canonical Matrix state before continuing work. Read the authoritative mandate and state applicable to your office; resolve current ownership, supersessions, obligations, blockers and executable next action; record a durable understood/bound receipt through the existing Intake/governance route; then continue only work authorized by your current mandate.

Do not create duplicate workers, schedulers, queues or shadow governance. Do not treat receipt of this directive as proof that sync occurred. A worker is synced only when its current canonical read, applicable mandate binding, receipt/readback and resulting disposition are evidenced.

## Category B itemized accountability
- **Expected outcome:** every previously unsynced worker consumes and binds to current canonical state.
- **Owner:** each existing worker for its own sync; ROOT/Intake for cross-Matrix reconciliation and visibility.
- **Required action:** read current canon → bind mandate → identify supersessions/obligations → persist understood/bound receipt → read back → resume lawful execution.
- **Dependency/blocker:** any unavailable repository, authority, receipt or runtime path must be recorded with exact attempted action, furthest state, blocker, recovery owner and next retry/reroute action.
- **Acceptance evidence:** worker-specific current-source read, mandate/digest verification where applicable, durable receipt and independent readback.
- **Persistence/readback:** use existing Intake and each office’s existing receipt surface; do not create a parallel system.
- **Safety/preservation:** current mandate boundaries and existing safety, finance, legal, security and publishing gates remain in force.
- **Disposition:** OPEN until each applicable worker’s sync is evidenced; publishing this directive alone is not completion.
- **Remaining work:** each unsynced worker must execute the sync and record evidence. ROOT/Intake must reconcile completion and leave blocked workers open with named recovery actions.
