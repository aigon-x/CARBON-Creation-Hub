# CATEGORY B OWNER DIRECTIVE — LIBRARIANS MUST DRAIN THE EXISTING INTAKE QUEUE

**Date:** 2026-10-12  
**Authority:** Direct Owner instruction  
**Scope:** MASTER / COFFEE / LIBRARIAN coordination of the existing ROOT/INTAKE queue, with each registered specialist retaining execution of its own assigned work.

## ORDER

**DRAIN THE EXISTING INTAKE QUEUE.** Do not let overdue obligations sit unresolved while AMX moves into market. This means real item-level dispositions and execution, not a report-only sweep, queue relabel, new tracker, or new queue.

## Required execution

1. Read the latest canonical Intake index, Blue State/mandate registry, and linked source records/issues. Reconcile current authority and supersessions. An issue-only census must not be represented as the complete Matrix queue.
2. Build/reconcile the current source-derived item census. For each item record priority, age/due signal where available, current owner, exact next action, dependency/blocker, acceptance evidence, and recheck condition.
3. Work P0 and overdue market/revenue-critical obligations first, then all other governance-ready work. Give every governance-ready item an explicit durable disposition: **MERGE / MODIFY / REJECT / ALREADY-SUBSUMED / HOLD**.
4. **Execute every lawful, available next action.** Route work to the existing accountable specialist and follow through on the receipt/readback. One blocked item must not stall other executable items. Do not stop after census, assignment, proposal, or status reporting.
5. HOLD only for a concrete unresolved authority, evidence, or dependency condition. Name the recovery owner, exact next action, and recheck condition. Preserve attempted action, furthest evidenced state, and blocker. Blocked work remains OPEN until verified completion or governed cancellation.
6. Reuse the existing Intake queue, canonical issues, trackers, and receipt surfaces. Do not create another queue, worker, scheduler, or parallel governance layer. Moving an item out of view, suppressing it, changing a label, or assigning it is not drainage.
7. Persist and independently read back item-level outcomes. Reconcile before/after counts by state and priority/age, owner/next-action completeness, verified closures, and remaining holds. Preserve closed/superseded history and lineage.
8. End with **INTAKE CLEARED** only if the full applicable source inventory has been reconciled and every governance-ready item has a verified disposition, with no due executable item left idle. Otherwise state **INTAKE NOT CLEARED** and identify every remaining item with owner, blocker/dependency, next action, acceptance evidence, and recheck condition. Clearly disclose any source that could not be inspected.

## Category B / Directive 23 accountability

- **Expected outcome:** overdue obligations are materially advanced or precisely held under a real blocker; no executable work is left sitting idle as AMX moves into market.
- **Owners:** MASTER / COFFEE / LIBRARIAN coordinate the census and drain; each registered specialist executes its owned actions; ROOT/Intake decides genuine authority conflicts.
- **Required action:** current-source census → prioritise → dispose/execute/route → persist → independently read back → continue.
- **Dependencies/blockers:** exact item-level gate, recovery owner, next action and recheck are mandatory.
- **Acceptance evidence:** source-derived before/after counts plus item-level receipts/readbacks; no false closures.
- **Persistence and safety:** existing canonical Intake surfaces only; preserve mandate boundaries and safety, legal, security, finance, privacy, and publication gates.
- **Disposition:** OPEN until verified drainage is evidenced. Posting this directive is not completion.
